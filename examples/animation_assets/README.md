# Rigged Blockbench robot

Generated by `tools/create_animated_robot.py` from the existing static Blockbench
robot. Includes six joints and three clips: Idle (2 s), Wave (2 s), Walk (1 s).
`robot.glb` contains all data. `robot.gltf` uses `animation data.bin`.

The native animation asset verifier loads and evaluates both formats. This is an
animation fixture. The playable two-robot project is `examples/animation_demo`,
with shared native playback nodes, skinned rendering and game checkpoints.
See `docs/animation.md` for current boundaries.
