# Animation playground

Open `project.json` in the editor, then Play. The left robot waves; the right robot
walks. Both share one GLB but keep independent clocks and deformed vertices.

Click the game viewport before using keyboard controls:

- 1/2/3: play Idle/Wave/Walk on the left robot.
- P/R: pause/resume; T: seek to one second.
- B/N: reverse/normal speed; X: stop and restore bind pose.
- S/L: save/load both robots through the whole-game checkpoint system.

The graph is generated by `tools/create_animation_demo.py` using the same nodes
available in the editor. `tools/verify_animation_workflow.py` checks a relocated
package in all four native hosts, including exact state/pixel continuation after
loading in a new process. `tools/verify_animation_editor.py` checks real editor
graph authoring, Undo/Redo, save/reopen and physical keyboard playback controls.

The renderer currently skins on the CPU and streams vertices to SDL_GPU.
Dedicated animation workspace, blending and finished/notify events remain open.
